How to Connect Google Cloud Firestore

This project uses Google Cloud Firestore as the persistent cloud database. Follow either option below:

Option A: Deploy to Google Cloud Run (Recommended for Practical Exam)

When deployed on Google Cloud Run, authentication is completely automatic! The Cloud Run container uses its attached Service Account identity.

  1. Create or select your GCP project in the Google Cloud Console.
  2. Create a Firestore database in Native mode (Region: asia-south1).
  3. Deploy with command: 
    gcloud run deploy student-task-manager --source . --region asia-south1 --allow-unauthenticated

Option B: Connect Locally for Development

  1. In GCP Console, go to IAM & Admin > Service Accounts.
  2. Create a service account with role Cloud Datastore User.
  3. Download its JSON key file and set environment variable: 
    # In Windows PowerShell:
$env:GOOGLE_APPLICATION_CREDENTIALS = "d:\path\to\service-account.json"
$env:GCP_PROJECT_ID = "your-gcp-project-id"
python app.py
